## Actual paths and instrumentation

All requests traverse the ORIGINAL BaseAgent.send -> UTE.new -> original encoder
registry -> original client adapter -> actual loopback protocol server ->
deterministic executor callback -> actual response -> original decoder registry.
A2A uses A2AStarletteApplication /message and its SDK executor interface. ACP uses
ACPStarletteApplication /acp/message and its async-generator interface. ANP uses
ANPSimpleNodeWrapper /anp/message with its existing answer callback and a locally
generated real DID. Its current send_message implementation is HTTP; no WebSocket
or E2E latency is claimed. Agora uses the existing toolformer=None client and
AgoraServerWrapper /message with the deterministic answer callback. The real
Agora Receiver is constructed with None toolformer, without model substitutes;
protocol negotiation/code generation are not invoked. No protocol wire format,
server route, adapter send logic or UTE conversion is reimplemented or patched.

The deterministic no-op receipt includes the entire input text's byte count and
SHA256, with a fixed-size response. The source payload is deterministic within
each protocol/size/phase/repetition; UUIDs, timestamps, ports and crypto identities
are generated by the original repository implementations. No fixed-timing or
perfect numerical-repeatability claim is made.

latency_ms equals the exact perf_counter_ns end-minus-start interval immediately
around awaiting BaseAgent.send (including real encode/transport/server/decode).
The original REQUEST_LATENCY metric is separately retained and must fit inside
that outer interval. Every success also requires one server POST and one executor
receipt matching the full payload byte count/digest. All 560 wall-clock intervals,
server counts, executor counts and per-condition statistics were independently
verified from saved raw data. Setup timers and warmups do not enter statistics.

encoded_request_bytes is the actual received HTTP body byte count, excluding
HTTP headers. ASGI observers forward original events unchanged and wrap the
original Starlette middleware stack; Flask instrumentation reads the original
request body. ute_encoded_bytes is also retained from the existing MSG_BYTES
metric to distinguish converter-boundary size from actual adapter serialization.
